## 实现

- 草稿和实际证据分开：复核只以工具取回的来源和已读取正文为证据，旧回答仅用于理解指代；工具错误和认证失败不会产生来源编号。仅网页模式仍隔离历史树洞证据及相关回答。
- 先核对具体断言，再根据修正项改写。核对费用、渠道、身份、校区、日期及适用条件，避免将“未知”写为“不适用”，或合并不同渠道收费。收费句本身需说明渠道，不能依赖后文补充。
- 所有草稿都经过启用的语义核对，包括没有检索结果的草稿；首次核对可补做遗漏的检索，后续核对不能开启新工具。普通聊天不因此要求搜索，但通常增加一次模型调用。
- 引用编号和显式数字字数上限由程序检查。字符数包括标点、空白、格式和引用；失败时在预算内改写，不截断答案，也不只替换编号来保留无依据断言。最终仍不合格则明确标为未完成。
- 核对输出采用严格结构，格式错误可重试。改写通过机械检查后，剩余次数可用于再次核对语义；为发现问题后的最后修正保留余量。
- 最终每轮最多 **4 次核对／格式重试／改写**，仍共享原 **90 秒、6 次工具、3 页树洞**预算。没有增加距离查询专用分支、固定答案或按案例名称路由。

新增 `review_calls`、`answer_repairs` 和发生格式重试时的 `review_format_retries` 指标。关闭 `ANSWER_REVIEW_ENABLED` 会跳过语义核对，引用与数字字数校验仍然执行。

## 验证范围与结果

自动化回归从 135 项增加到 **152 项**，覆盖核对格式恢复、无来源草稿补查、改写引入错误后的修正、过长回答、无效引用、证据隔离、权限、取消和总截止时间。测试全部使用合成数据，未读取本地真实凭据或请求外部服务。存在一条原有 TestClient 依赖弃用警告。

前端 TypeScript 检查与生产构建通过；启动、后端、前端 API 代理检查通过。首次启动冒烟的代理请求曾超过 5 秒，重跑通过，保留为一次启动瞬态失败。最终服务已重新启动。

真实 API 集成验证通过：执行调研计划、网页检索、树洞检索和帖子读取，返回 W/C 引用；网页正文读取遇到 `page_unsupported_type` 后仍完成回答，仅网页追问正确更新校区且不调用树洞。该检查只证明调用链和恢复路径，不是事实质量评分。真实 token 过期刷新仍未主动触发。

评测使用真实 `deepseek-flash`，关闭思考，输出上限 4096 tokens，单次模型 45 秒，搜索 `advanced`。合成案例的检索由固定 fixture 提供；`live_*` 使用真实检索。距离及距离干扰案例均排除，现有案例总数为 17。

### 最终修正预算的复测

将上限调至 4 次的原因是给“核对→改写→再次核对”后的修正保留一次机会，而非延长总截止时间。`step5-repair-budget4` 重跑 4 个重点案例、7 轮：

| 案例 | 字符数 | 整组耗时 / 模型调用 | 结果 |
| --- | --- | --- | --- |
| service_scope | 80 / 62 | 7.97秒 / 8次 | 通过渠道、对象、校区和长度检查 |
| policy_experience | 559 / 142 | 10.74秒 / 8次 | 核心时限与适用范围正确；仍有楼层ID表述问题 |
| campus_unavailable | 225 | 16.52秒 / 5次 | 认证失效后完成网页回答，无伪造C引用 |
| live_policy | 246 / 91 | 40.92秒 / 12次 | 正常完成300/100字符限制；枫林适用性待核实。收费句的渠道限定仍应更明确，随后补强通用核对要求并复测 |

同一案例不同运行的检索结果、模型输出和网络耗时均会变化。以上不是配对统计实验，也不据此宣称稳定提速；新增核对会增加调用及 token 用量。该真实办事样本两轮累计172809 tokens，完整用量与缓存指标保留在样本记录中。

补强收费句的渠道限定后，`step5-repair-live-confirm` 再次真实复测：两轮 **222/80 字符**、共30.23秒、12次模型调用，均正常完成；主回答说明自助打印渠道，追问保留枫林终端与渠道可用性待核实。但首轮逐字引用了一条短帖全文，与题目“不复制完整帖子”不完全一致，已在样本中脱敏，人工仍记为部分通过。字数和失效恢复改善不能掩盖这项剩余输出问题。

## 保留的限制

语义核对仍由模型完成，无法保证每次正确。完整回归中有漏补查、漏读帖、楼层ID被当作序号的残留，真实案例还出现短帖逐字引用，简短回答也可能过度保守。程序能确保输出不带不存在的标准引用编号、不超过已识别的数字字数上限，并在明确失败时标注未完成；这不等于自动证明每个结论有充分语义支持，也不保证其余自然语言要求均已满足。

本轮不继续优化距离题；真实 token 自然过期后的刷新没有主动联测。第六步报告应保留这些边界，不能写成17组全通过或真实刷新已验证。真实树洞正文未写入本记录或脱敏样本，只有来源元数据及必要的回答摘要。
