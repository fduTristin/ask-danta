### 发现与处理

1. **正文读取夹具失真**：旧 `read_gap` 标题为“演示大学”，URL 却指向复旦研究生院，摘要也声称没有时限；模型拒绝把该页面用于演示大学是合理现象。已使用 `example.org/synthetic/materials` 和匹配摘要，保留正文里的 3 工作日。该修复改善测试有效性，不能据此宣称真实网页能力提升。
2. **分页语义**：初次 `source_conflict` / `post_injection` 把剩余预算说成“还有约一页未读”。修改 Skill 与核对提示后，定向 `partial_thread` 正确说只返回部分讨论，未复现该错误；保留旧答案。
3. **无效引用**：`campus_unavailable` 的最新样本中，树洞 401 后网页成功，候选仍出现无效来源编号；程序拒绝发布，最终 `incomplete`。这说明引用保护生效，但用户任务未成功完成，不能记作“恢复成功”。初次合成样本和真实网页浏览器恢复均成功，仍不能掩盖波动。
4. **动作和简洁性**：浏览器首次失效恢复回答声称读过官网，但只有搜索工具，属于失败。补充动作核对后复测不再有该声明。研究生院官网查询最终只给名称和引用；复杂办事回答仍没有稳定遵守字数。
5. **真实办事证据**：命中研究生院[缴费办法](https://gs.fudan.edu.cn/_upload/article/files/ef/1e/7f02a0c544d5a9ceb1af290c7984/0d9dd02b-8480-4765-aaa3-c91ccc0bcd92.pdf)、[研究生电子学籍证明说明](https://icampus.fudan.edu.cn/4e/b6/c33159a413366/page.htm)以及本科生终端指南；真实树洞分别读取 #753874、#629923 的部分楼层。主要问题是回答超过 300/100 字要求，且追问把纸质收费与电子渠道混在一起，或将“尚未确认枫林适用性”说成“不适用于枫林”。这些结论不能直接作为办事建议；人工评审判未完全通过。

本次网页排名、命中 URL、帖号及模型调用数都有变化。改进前后仅是单次观测，不能把速度变化归因于提示词，更不能用某个成功样本证明稳定性。

## 未解决项
