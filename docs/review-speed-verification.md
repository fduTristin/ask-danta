# 答案核对速度验证

2026-11-08 使用已配置的 `deepseek-flash` 真实模型，对两组合成资料分别测试高强度思考、低强度思考与非思考模式。每组输入包含 24 条合成来源及相同的核对提示，输出上限为 16384 Token，单次超时为 90 秒。没有读取或发送真实聊天记录、树洞帖子，没有调用搜索接口。

## 小样本结果

| 合成场景 | 高强度 | 低强度 | 非思考模式 |
| --- | ---: | ---: | ---: |
| 将纸质收费错误用于电子渠道 | 9.906 秒 | 9.078 秒 | 2.125 秒 |
| 草稿与已有申请说明一致 | 5.562 秒 | 5.078 秒 | 1.141 秒 |

六次响应都通过预设检查：能够解析为合法核对结果，第一组提出修正，第二组没有要求不必要的修正，并通过已有证据检查。输出 Token 数分别为：第一组 1444／1217／144，第二组 687／577／17。

本次小样本中，非思考模式核对平均约 1.63 秒，高强度约 7.73 秒，低强度约 7.08 秒。第二组反转测试顺序以减少固定顺序影响，但网络、服务负载与缓存仍可能影响结果。每个场景每种模式仅运行一次；这不是长期性能基准，也不代表完整问答可以按相同比例提速或复杂事实核对的整体准确率不变。

## 实现与约束

核对与修订采用非思考模式，主回答和检索决策继续使用用户设置。完整证据仍进入核对请求，仅删除已经包含在证据中的重复原文副本，并紧凑序列化 JSON。未知引用、复制完整帖子、字数限制、用户明确要求的检索操作等程序检查保留，修订后的重新核对和总调用／时间预算保留。

新增核对耗时与用量指标，用于后续观察实际问题。单次模型默认超时提高为 120 秒、整轮提高为 300 秒；这些是失败保护上限，不会要求模型等待到时限。

## 复现

```sh
uv run --frozen python scripts/benchmark_review.py --live --output .private/verification/review-speed-new.json
```

此命令消耗六次真实模型请求额度；使用合成证据，不执行外部检索。输出只包含模式、模型名称、耗时、用量及检查结果，不保存密钥、模型内部思考或真实用户资料。原始结果保存在本机 `.private/verification/review-speed-20261108.json`。
