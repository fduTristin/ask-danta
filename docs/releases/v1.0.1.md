# Ask Danta · 问问旦挞 1.0.1

[中文](#中文) · [English](#english)

## 中文

1.0.1 改进了多对话使用体验：等待一个回答时，可以切换到其他对话继续提问。

### 本次更新

- **切换对话不中断回答**：回答生成时可直接切换或新建对话，无需先停止；返回原对话后可查看进度或结果。
- **多个对话可同时回答**：不同对话可以同时生成答案。“停止回答”只停止当前对话，其他对话继续进行。
- **切换时保留草稿**：其他对话完成回答后，不会把你切回去，也不会覆盖当前正在编辑的问题。
- **输入框位置更统一**：电脑和手机浏览器中的新对话输入框均位于底部，欢迎内容在聊天区域居中显示。

## English

Version 1.0.1 improves working with multiple conversations: while one answer is being generated, you can switch to another conversation and ask a different question.

### What's new

- **Switch without interrupting an answer:** open another conversation or start a new one while an answer is being generated. Return to see its progress or result.
- **Generate answers in multiple conversations:** different conversations can run at the same time. Stopping an answer affects only the current conversation.
- **Keep your draft while switching:** an answer finishing in another conversation will not switch you back or overwrite the question you are editing.
- **A consistent input position:** the input box stays at the bottom of new conversations on desktop and mobile browsers, with the welcome message centered in the chat area.

Exit the previous version, then install the 1.0.1 package for your system and architecture. Desktop upgrades preserve settings and chat history, including saved service keys. Automatic updates are not currently available.

First-time users need to configure a model service in Settings. Real web search also requires a Tavily API key; campus forum search requires a login and the appropriate access permissions. The default web search uses synthetic examples. Model and search services may incur charges. See the [user guide](https://github.com/fduTristin/ask-danta#readme) for setup requirements.

### Usage notes

- Answers continue when you switch conversations within the application; unfinished answers do not continue after you close the application.
- Installers are not signed with developer certificates, so Windows SmartScreen or macOS Gatekeeper warnings may appear. Linux AppImage requires FUSE; a DEB package is also available.
- Questions, relevant context, and retrieved material are sent to your configured model service. Citations and automated review do not guarantee accuracy.

[Report an issue](https://github.com/fduTristin/ask-danta/issues) with your app version, operating system, and reproduction steps. Do not include service keys, credentials, or private material.
