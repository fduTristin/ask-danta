# Ask Danta · 问问旦挞 1.0.0

[中文](#中文) · [English](#english)

## 中文

Ask Danta 是面向复旦大学校园场景的检索问答应用，结合公开网页与访问权限范围内的树洞资料，为校园办事、课程学习和校园生活问题提供带来源引用的回答。

1.0.0 提供 Windows、macOS 和 Linux 桌面安装包，也支持从源码运行。

安装包包含运行环境，无需另装 Python、Node.js 或 uv。AppImage 运行环境需要 FUSE，也可选择 DEB 包。

1. 启动应用，在“设置”中配置模型接口地址、模型名称和 API Key。
2. 如需真实网页搜索，选择 Tavily 并填写 Tavily API Key。默认网页搜索使用标记为合成样例的数据，不能作为真实资料；该模式仍需配置模型服务。
3. 如需树洞检索，在“设置 → 账号”中登录。树洞功能需要具备相应社区访问权限，并遵守社区规则；未登录可使用仅网页模式。

模型和搜索服务可能产生费用，取决于所用服务及账户额度。

### 主要功能

- **多源检索**：支持网页搜索与正文读取、树洞搜索与帖子上下文读取，并按需显示树洞配图；提供自动选择、仅网页、网页与树洞三种模式。
- **来源引用与答案核对**：回答关联网页和树洞来源，可展开查看摘要、链接与日期；默认核对答案与证据，并按需修订。仅网页模式排除先前对话中的树洞证据。
- **多轮问答**：支持追问、复制、失败重试和历史问题编辑。编辑会替换该轮及后续内容，提交前提示替换范围。
- **执行过程展示**：显示检索、读取和核对等步骤、工具状态与耗时，支持停止当前请求。
- **本地会话与设置**：保存消息、引用、执行记录和服务配置，支持会话新建、切换、重命名与删除；设置接口不返回 API Key 原文。

### 数据与已知限制

- 会话、设置和树洞凭据保存在本机。API Key 以本地 JSON 文件保存，程序设置文件访问权限，不对密钥另行加密。
- 模型请求会将问题、相关上下文和检索材料发送至已配置的模型服务；启用 Tavily 时，检索词会发送至 Tavily。
- 来源引用和自动核对不能保证回答正确，正式政策与办事要求应以官方信息为准。
- 当前面向单用户本地使用，不支持多用户账号、跨设备同步、旧消息版本切换或自动更新。
- 安装包未使用开发者证书签名，macOS 使用 ad-hoc 签名，可能出现 SmartScreen 或 Gatekeeper 提示。
- 升级前请退出应用。桌面升级保留既有设置与会话，源码开发数据不会自动迁入桌面版。
- 安装包经过各目标平台的自动构建与独立后端启动检查；这些检查不代表所有平台上的完整功能验收。

## English

Ask Danta is a research and Q&A application for the Fudan University campus community. It uses public web sources and campus forum material within the user's access permissions to answer questions about campus procedures, courses, and everyday life, with source citations.

Version 1.0.0 provides desktop packages for Windows, macOS, and Linux, plus support for running from source.

Packages include the runtime; no separate Python, Node.js, or uv installation is required. AppImage requires FUSE; a DEB package is also available.

1. Open Settings and configure your model endpoint, model name, and API key.
2. For real web search, select Tavily and enter a Tavily API key. The default search provider returns labeled synthetic examples, which are not real evidence. A model service is still required in this mode.
3. For campus forum search, sign in under Settings → Account. You must have the appropriate community access permissions and follow its rules. Web-only mode is available without a campus login.

Model and search services may incur charges, depending on your providers and account quotas.

### Features

- **Multi-source search:** search and read public web pages and campus threads, with forum images available on demand. Choose automatic, web-only, or web-plus-campus sources.
- **Citations and answer review:** inspect source summaries, links, and dates. Answer review and revision are enabled by default. Web-only mode excludes campus evidence from earlier conversation turns.
- **Multi-turn conversations:** ask follow-up questions, copy messages, retry failed answers, and edit earlier questions. Editing replaces that turn and all subsequent content; the editor explains the scope before submission.
- **Execution progress:** see search, reading, and review steps, tool status, and elapsed time, and stop the current request.
- **Local conversations and settings:** persist messages, citations, execution records, and configuration. Create, switch, rename, or delete conversations. The settings API does not return API key values.

### Data and known limitations

- Conversations, settings, and campus credentials are stored locally. API keys are saved in a local JSON file with file access restrictions; the application does not separately encrypt them.
- Model requests send questions, relevant context, and retrieved material to the configured model provider. When Tavily is enabled, search queries are sent to Tavily.
- Citations and automated review do not guarantee accuracy. Consult official sources for formal policies and procedures.
- The application is intended for local, single-user use. Multi-user accounts, cross-device synchronization, message version switching, and automatic updates are not included.
- Packages are not signed with developer certificates; macOS uses ad-hoc signing. SmartScreen or Gatekeeper warnings may appear.
- Exit the application before upgrading. Desktop upgrades preserve settings and conversations; source-development data is not imported automatically.
- Packages undergo automated builds and standalone backend startup checks on their target platforms. These checks do not constitute comprehensive functional testing on every platform.
