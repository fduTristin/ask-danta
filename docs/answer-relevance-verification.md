# 回答相关性与自然收尾验收

日期：2026-11-02。用户反馈课程评价末尾突然追加教师院系和职称，导致回答收尾不自然。本轮处理通用的内容取舍，没有在生产代码中增加姓名、课程名匹配或固定答案。

## 修改

- 生成、独立核对、改写共用 `ANSWER_STYLE`：先回答当前问题，不要求用完来源，不在体验评价中追加无关身份背景。用户明确询问身份或需要消歧时仍保留必要信息。
- 评价限定为检索到的具体经历；纯提问不算评价，重复转述不增加独立样本，不从个别成绩推断普遍给分或复习效果。
- 一般咨询使用简短判断与必要要点，限制集中说明；不逐项报告被排除的素材，不以引用清单、检索过程或新的背景话题收尾。
- 复核把无关身份拼接、没有新增信息的素材复述列为相关性问题。改写收到删除要求后直接删除，不用“这条不是证据”的说明替代删除。不增加额外润色调用，继续使用现有调用和时间预算。
- 应用内 `ask-danta-research` Skill 同步上述原则；读取条数恰好等于服务报告的回复计数，也不代表已完整读帖。

## 方法与证据

新增 `course_experience` 合成案例，现有案例从 19 组增为 20 组。虚构教师档案含院系/职称；四条合成帖子包含两条不同年份的直接经历、一条纯提问、一条无新增经历的转述。连续三轮分别询问教师身份、课程体验、再次确认身份，检查信息是否按本轮意图取舍。

使用真实 `deepseek-flash`，检索与帖子均由合成适配器返回；未调用真实 Tavily 或树洞，未重新检索或验证用户所提教师的实际评价。所有结论仅针对合成情境中的模型行为。原始记录在本地 `.private/quality/`，可分享的合成回答摘要见 [对照样本](answer-relevance-samples.json)。

| 检查 | 结果 |
| --- | --- |
| 原规则、同一条带身份尾句的草稿 | 完整检索元数据下，旧复核提出其他修正，没有指出无关的院系/职称尾句 |
| 新规则、相同草稿与证据 | 复核明确要求删除身份句及 W1 引用，改写结果只保留课程体验与证据边界 |
| 最终采用版本，课程案例重复 2 次、每次 3 轮 | 6 轮流程均完成；两轮课程回答均无身份尾句，也未引用纯提问和转述来汇报排除过程；四轮明确身份问答均保留正确的院系/职称及 W1 |
| 后端隔离回归 | 175 项通过；后续定向的质量、调研与评测脚本检查 37 项通过，保留既有 TestClient 弃用提示 |
| 本地运行 | 更新后重启服务，前端代理返回 stage=6；重启前后原有 3 段会话 ID 一致 |

最终采用配置对应 `natural-course-relevance-20261102.json`；原规则基线为 `natural-course-before-20261102.json`，固定草稿对照为 `natural-course-tail-probe-final-20261102.json`。最早一次固定草稿探针漏填本轮检索动作元数据，触发了额外的“未搜索”判断，已保留但不作为最终对照依据。

## 仍有的限制

- 最终两条课程回答虽然去掉身份尾句和无用素材枚举，仍有报告感。一条把“愿意自学”概括为风险相对可控，条件推断仍偏强；另一条保留了服务报告回复数等不必要的流程细节。因此本轮通过的是目标尾句及按问题取舍的定向检查，不是所有语义与自然度全面通过。
- 一次中间版本出现“取得数量等于回复计数，所以已读全部”的错误；已收紧读取范围说明，后续采用版本没有再出现该断言，但不宣称一般性消除。
- 另试过给一般咨询加入默认数字长度区间，`natural-course-concise-20261102.json` 中一轮遇到复核预算用尽。不能仅凭这一次归因于长度指引；为避免新增数字长度目标，本次未采用该修改，恢复到已经验证的相关性版本。原有用户明确字数限制继续执行，失败记录保留。
- 提示词约束仍由模型执行，不保证每次输出一致；不靠关键词删尾句或降低事实检查来制造通过。既有第五步语义质量和上游可用性限制继续有效。

## 复现

```powershell
uv run --frozen pytest -q
uv run --frozen python -X utf8 scripts/evaluate_quality.py --label fresh-course-style --case course_experience --repeat 2
```

评测会调用已配置的模型并消耗额度；检索、教师和课程资料均为明确标注的合成情境，样本不能用来评价任何真实教师。
